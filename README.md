# 토브공방 판매상품 추가본

기존 GitHub Pages 홈페이지의 상품 사진·상세페이지 추가본입니다.

## 적용
압축을 풀고 index.html, style.css, 상품별 html, images 폴더 및 정책 html을 기존 저장소의 같은 위치에 업로드합니다. images 폴더를 반드시 함께 올리세요.
index.html을 더블클릭해 로컬에서도 확인할 수 있습니다.

## 반영 사항
- Martin GPCPA4: 1,250,000원 (사용자 확정 가격), 2014년 구입·사용감 있음.
- 나머지 7상품: 사진 가격표 기준. Boong은 사진에서 150,000원으로 읽어 적용했습니다.
- 모델명 불명확한 Cort는 브랜드와 바디 형태로 표시했습니다.
- 제품별 상세페이지, 이메일/전화 구매 문의, 배송·환불 안내.
- 기존 사업자정보 및 정책 문서 유지, 이전 수정 ZIP에서 빠져 있던 style.css 복구.
- 온라인 결제/에스크로 연결은 아직 없으며 구매 문의 단계입니다.

## 실제 주문 전 확정할 정보
각 상품의 신품·중고 구분, 흠집·수리 이력, 구성품, 정확한 모델명, 배송비.
심사 통과를 보장하는 패키지가 아니며 결제 연동은 별도 작업입니다.
