# TOV Workshop Official Website

토브공방 공식 홈페이지용 정적 사이트입니다.

## GitHub Pages 배포
1. 이 저장소에 `index.html`, `style.css`, `privacy.html`, `terms.html`, `refund.html`을 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source**를 `Deploy from a branch`로 선택합니다.
4. Branch를 `main`, Folder를 `/(root)`로 선택하고 Save 합니다.
5. 잠시 후 `https://mingiu21.github.io/TOV-Workshop/` 형태의 공개 주소가 생성됩니다.

`[입력 필요]`로 표시된 아래 항목을 실제 사업자등록 정보와 일치하도록 수정하세요.
- 대표자
- 사업자등록번호
- 사업장 주소
- 대표 전화
- 이메일
